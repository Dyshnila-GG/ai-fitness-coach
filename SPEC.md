# AI Fitness Coach — спецификация продукта (MVP)

> Источник правды для разработки. Claude Code реализует этапы из раздела 13 по порядку и отмечает статус в конце файла.

## 1. Суть

Мобильное приложение (iOS + Android) — персональный AI-тренер.
Личное приложение для 2 пользователей (автор и друг): без публикации в App Store / Google Play, без монетизации. Запуск — всегда в Expo Go (без dev build).
Пользователь проходит калибровку, задаёт цели, получает готовую программу или собирает свою тренировку, проходит её пошагово (разминка → упражнения → заминка), логирует каждый подход, оценивает сложность. AI анализирует данные, задаёт уточняющие вопросы и генерирует следующую тренировку так, чтобы максимально приблизить пользователя к цели.

**Проблема:** без тренера люди тренируются хаотично, не знают рабочих весов, не отслеживают прогрессию и бросают.
**Для кого:** новички и любители (зал / дом), тренируются 2–5 раз в неделю без личного тренера.

## 2. Цели MVP

1. Пользователь проходит калибровку и получает первую тренировку < 3 мин.
2. ≥ 60% начатых тренировок завершаются с оценкой.
3. После каждой тренировки AI выдаёт следующую с обоснованной прогрессией (вес / повторы / объём).
4. Приложение работает во время тренировки без интернета.

## 3. Не входит в MVP (v2+)

- Питание и калории — отдельный большой модуль.
- Свободный AI-чат — в MVP только уточняющие вопросы AI.
- Apple Health / Google Fit, часы, соцфункции, видео вместо гифок.

## 4. Калибровка (онбординг)

Пошаговый экран, 1 вопрос на экран, прогресс-бар, можно пропустить необязательные.

| Поле | Значения | Обяз. |
|---|---|---|
| Пол | муж / жен | да |
| Возраст | 16–80 (дата рождения) | да |
| Рост | см / ft-in | да |
| Вес | кг / lb | да |
| Уровень | новичок (<6 мес) / средний (6 мес–2 г) / продвинутый (>2 лет) | да |
| Где тренируется | зал / дом / улица (мультивыбор) | да |
| Инвентарь (если дом/улица) | гантели, штанга, гири, турник, брусья, резинки, скамья, ничего | да* |
| Дней в неделю | 2–6 | да |
| Режим тренировки | Light (~50 мин) / Hard (90–120 мин) / смешанный | да |
| Ограничения | зоны: шея, плечи, локти, запястья, спина (поясница), колени, голеностоп + текст «что неудобно делать» | нет |
| Кардио | в начале (разминка) / в конце / не нужно | да |
| % жира, обхваты | число | нет |
| Единицы | кг / lb | да (по умолчанию из локали) |

Все поля редактируются в профиле. Изменение → пересчёт плана.

## 5. Цели

Выбор: **1 основная + до 1 дополнительной**.

1. Набор мышечной массы
2. Сила (рост рабочих весов)
3. Жиросжигание / рельеф
4. Рекомпозиция (минус жир, плюс мышцы)
5. Выносливость
6. Общая форма и здоровье
7. Мобильность и здоровая спина

Цель задаёт параметры по умолчанию:

| Цель | Повторы | Подходы | Отдых | RIR* | Темп |
|---|---|---|---|---|---|
| Масса | 6–12 | 3–4 | 90–120 с | 1–2 | 3-0-1-0 |
| Сила | 3–6 | 4–5 | 150–240 с | 1–3 | 2-1-X-0 |
| Жиросжигание | 10–15 | 3 | 45–75 с | 1–2 | 2-0-1-0 |
| Рекомпозиция | 6–12 | 3–4 | 90 с | 1–2 | 3-0-1-0 |
| Выносливость | 15–20 | 2–3 | 30–60 с | 2–3 | 2-0-1-0 |
| Общая форма | 8–12 | 3 | 60–90 с | 2 | 2-0-1-0 |
| Мобильность | 10–15 / по времени | 2–3 | 30–60 с | 3 | медленно |

*RIR — сколько повторов «осталось в запасе». Темп: опускание-пауза-подъём-пауза (сек), X = взрывно.

## 6. База упражнений

**Принцип:** 5–10 самых продуктивных упражнений на группу, у каждого — альтернативы с другим инвентарём (свободный вес ↔ тренажёр ↔ свой вес).

**Поля упражнения:** `id`, `name_ru`, `name_en`, `primary_muscles[]`, `secondary_muscles[]`, `equipment` (barbell, dumbbell, machine, cable, smith, bodyweight, kettlebell, band), `pattern` (push_h, push_v, pull_h, pull_v, squat, hinge, lunge, isolation, core, cardio, mobility), `difficulty` (1–3), `is_compound`, `is_unilateral`, `default_tempo`, `instructions[]` (3–6 шагов), `mistakes[]`, `contraindications[]` (зоны из калибровки), `media_url` (GIF), `alternatives[]`.

**Замена:** кнопка «Заменить» → список альтернатив с тем же `pattern` и мышцей; фильтр «свободный вес / тренажёр / свой вес».

**Стартовый набор (seed):**

- **Грудь:** жим штанги лёжа, жим гантелей на наклонной, жим гантелей лёжа, жим в тренажёре, сведения в кроссовере, бабочка (pec deck), отжимания, брусья (акцент грудь).
- **Спина:** подтягивания, тяга верхнего блока, тяга штанги в наклоне, тяга гантели одной рукой, тяга горизонтального блока, тяга Т-грифа с упором, пуловер в блоке.
- **Плечи:** армейский жим, жим гантелей сидя, жим в тренажёре, махи гантелями в стороны, махи в кроссовере, обратные разведения, тяга каната к лицу (face pull).
- **Бицепс:** подъём штанги, подъём гантелей, молотки, подъём на наклонной скамье, подъём на блоке, скамья Скотта.
- **Трицепс:** жим узким хватом, разгибания на блоке, французский жим, разгибание из-за головы на блоке, брусья (акцент трицепс), отжимания узкие.
- **Квадрицепс:** присед со штангой, фронтальный присед, жим ногами, гакк-присед, болгарские выпады, разгибания ног, гоблет-присед, выпады.
- **Задняя поверхность / ягодицы:** румынская тяга, становая тяга, сгибания ног лёжа, сгибания сидя, ягодичный мост со штангой (hip thrust), гиперэкстензия, отведение ноги в кроссовере.
- **Икры:** подъём на носки стоя, сидя, в жиме ногами.
- **Кор:** планка, боковая планка, подъём ног в висе, скручивания на блоке, ролик, dead bug, Pallof press.
- **Кардио / разминка:** беговая дорожка, велотренажёр, гребной, скакалка, суставная разминка (комплекс 5 мин).

**Медиа:** GIF нельзя брать из интернета без лицензии. MVP — поле `media_url` + плейсхолдер; источник (лицензированный датасет, напр. ExerciseDB по лицензии, или свои анимации) — открытый вопрос (раздел 15).

## 7. Тренировки

### 7.1 Готовые программы
| Программа | Дней | Для кого |
|---|---|---|
| Push / Pull (2×/нед, через 2 дня) | 2 | мало времени, Hard |
| Push / Pull / Legs | 3–6 | средний+, масса |
| Upper / Lower | 4 | все уровни |
| Full Body | 2–3 | новички, жиросжигание |
| Дома: свой вес + гантели | 3 | дом / улица |

Push = жимы «от себя» (грудь, плечи, трицепс). Pull = тяги «на себя» (спина, бицепс). Ноги распределяются по дням в программах без отдельного Legs.

Режим **Light (~50 мин):** 4–5 упражнений, меньше подходов, короче отдых.
Режим **Hard (90–120 мин):** 6–8 упражнений, больше объёма, полная разминка и кардио.

Система подбирает программу по калибровке и цели; пользователь может сменить.

### 7.2 Своя тренировка
Конструктор: название → добавить упражнения из базы (поиск, фильтр по мышце / инвентарю) → порядок drag-and-drop → подходы / повторы / вес / темп / отдых для каждого → сохранить как шаблон.

### 7.3 Структура тренировки
1. **Разминка:** кардио 5–10 мин (бег / вело / гребля, выбор) + суставная разминка.
2. **Основная часть:** упражнения по порядку (базовые → изолирующие).
3. **Кардио в конце** (если выбрано в калибровке).
4. **Заминка:** 3–5 мин растяжки.

**Разминочные подходы** (авто для базовых): 40% × 10, 60% × 6, 80% × 3 от рабочего веса. Можно выключить.

## 8. Экран тренировки (плеер)

Для каждого упражнения видно: название, GIF, кнопка «Как делать» (шаги + ошибки), разминочный вес, рабочие подходы (вес × повторы, темп, отдых, RIR-цель), вес прошлой тренировки.

Действия:
- отметить подход: факт. вес и повторы (по умолчанию = план, правка в 1 тап);
- **+ подход / − подход**;
- таймер отдыха стартует автоматически (вибрация + звук), можно +15 / −15 с;
- **Заменить** упражнение / сменить инвентарь (свободный вес ↔ тренажёр);
- пропустить упражнение;
- заметка к упражнению;
- флаг «Больно» → предложение заменить упражнение + отметка для AI.

Работает офлайн, прогресс сохраняется локально каждые изменения, синхронизация при появлении сети. Если приложение закрылось — тренировка продолжается с места остановки.

## 9. После тренировки

- Общая сложность 1–10 (RPE сессии).
- Быстрые чипы: сон, энергия, «была боль» (зона).
- Комментарий (текст).
- Итог: длительность, объём (кг), рекорды (PR).

## 10. AI-анализ и генерация следующей тренировки

**Поток:**
1. После оценки → AI получает: профиль, цель, историю последних 4–6 недель (агрегировано), текущую тренировку (план vs факт), оценку, комментарии, флаги боли.
2. AI может задать **до 3 уточняющих вопросов** (с вариантами ответа + свободный ввод). Пример: «Жим дался легко на всех подходах — повысить вес на 2,5 кг или добавить подход?»
3. AI генерирует следующую тренировку этого типа → пользователь видит изменения с пояснением («+2,5 кг на жиме: все подходы выполнены с запасом»).

**Правила прогрессии (детерминированная основа, AI работает поверх):**
- Двойная прогрессия: все подходы на верхней границе повторов с RIR ≥ цели → вес +2,5 кг (верх тела) / +5 кг (низ тела) или +1 шаг гантелей.
- Не добил нижнюю границу 2 тренировки подряд → вес −5–10%.
- RPE сессии ≥ 9 две тренировки подряд или жалобы на усталость → облегчённая неделя (deload: −40% объёма).
- Флаг боли → упражнение заменяется альтернативой без нагрузки на зону.
- Лимиты объёма: 10–20 рабочих подходов на группу мышц в неделю (по уровню).

**Техника:**
- Вызов Claude API только через серверную функцию (Supabase Edge Function), ключ — в секретах сервера.
- Ответ — строгий JSON по схеме (zod), валидация на сервере; упражнения — только из базы (`exercise_id`); при ошибке — повтор 1 раз, затем fallback на детерминированную прогрессию.
- Модель — из переменной окружения `ANTHROPIC_MODEL`.
- Все запросы/ответы логируются в `ai_generations`.
- Лимит: 20 генераций в сутки на пользователя.

## 11. Прогресс

- История тренировок (календарь + список).
- По упражнению: график рабочего веса и расчётного 1ПМ, объём, рекорды.
- Недельный объём по группам мышц.
- Вес тела (график), обхваты.
- Серия (streak) — выполненные запланированные тренировки подряд.

## 12. Технологии

| Слой | Выбор |

| Графики | victory-native |
| Языки | i18next: русский (основной), английский |
| Тесты | Jest + React Native Testing Library; unit-тесты логики прогрессии обязательны |

## 14. Безопасность и юридическое

- Дисклеймер при онбординге: «не медицинская рекомендация, при болях/заболеваниях — к врачу» (обязательное подтверждение).
- AI не даёт медицинских советов; при флаге боли — рекомендация прекратить упражнение.
